# Compte Boost

Logiciel de contrôle des boosts par page : saisie horodatée par les employés, écart entre messages des boosts et messages réels, comparaison sur 3 jours, récapitulatifs (jour, semaine, mois, année), calendrier, validation par l'administrateur.

## Version en service

L'application qui enregistre les données fonctionne sur claude.ai :
https://claude.ai/artifact/SiH7ckwK2MM7wetWjF6QW4

Le fichier `index.html` de ce dépôt est une copie du code. Ouvert en dehors de claude.ai, il fonctionne seulement en mode exemple (aucune donnée n'est enregistrée).
